# 📂 插件安装

> 主题分类笔记 - 最后更新: 2026-09-03
> 相关对话数: 1

## 概述

DSH (DeepSeek Harness) 插件安装的最佳实践和常见问题。

## 安装流程

### 标准安装命令

```bash
# 从本地路径安装（推荐）
dsh plugin --profile web add /path/to/plugin

# 从 npm registry 安装
dsh plugin --profile web add plugin-name
```

### 安装后必须执行

1. **重启 DSH**: 插件不会热加载，必须重启
2. **检查构建产物**: 确保 `lib/` 目录存在
3. **验证注册**: 检查 `cordis.patch.yml` 是否正确

## 常见问题

### 1. Duplicate Loader Entry ID

**错误信息**:
```
duplicate loader entry id: xxx
```

**原因**: `dsh plugin add` 已自动注册插件，手动编辑 `cordis.patch.yml` 导致重复

**解决**: 清空 `~/.dsh/profiles/web/cordis.patch.yml` 为 `[]`

### 2. JSON BOM 错误

**错误信息**:
```
SyntaxError: Unexpected token ''
```

**原因**: PowerShell `Set-Content -Encoding UTF8` 写入 BOM 头

**解决**: 
```powershell
# 使用 ConvertTo-Json 重写
$json | ConvertTo-Json -Depth 10 | Out-File file.json -Encoding utf8NoBOM
```

### 3. settingsNamespace export 不存在

**错误信息**:
```
The requested module '@deepseek-ai/dsh-settings' does not provide an export named 'settingsNamespace'
```

**原因**: 插件依赖旧版 API（0.1.1-rc.2），DSH 实际安装新版（0.1.2-alpha.x）

**解决**: 修改插件源码，移除 `settingsNamespace()` 包装

### 4. 客户端依赖缺失

**现象**: 插件加载失败，浏览器控制台报错

**原因**: 插件依赖的三个包不在 DSH 种子表中

**解决**: 添加到 `package.json` 的 dependencies 和 bundles

## 调试技巧

1. 查看 DSH 启动日志，定位具体错误
2. 检查插件的 `lib/` 构建产物是否完整
3. 确认 `package.json` 的 `dsh.bundle.patch` 配置
4. 验证 `cordis.patch.yml` 没有重复条目
